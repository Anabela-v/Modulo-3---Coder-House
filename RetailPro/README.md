# 📊 Proyecto Data Analytics: Ventas_Tech_DB (RetailPro)

Repositorio creado como parte de la certificación en Data Analytics de **Coderhouse**. Su objetivo es construir el back-end transaccional y analítico para una cadena de tiendas de tecnología.

---

## 🛠️ Tecnologías Utilizadas
* **Base de Datos:** Relacional (Modelo 3NF).
* **Gestor de Base de Datos / Lenguaje:** SQL Server (Transact-SQL).
* **Control de Versiones:** Git & GitHub.

---

## 📂 Estructura del Repositorio
El repositorio está organizado en las siguientes etapas del proyecto:
1. **`ventas_tech_db.sql` (Módulo 3):** Script DDL y DML para la creación de la base de datos, definición de tablas (`categorias`, `clientes`, `productos`, `ventas`), restricciones de integridad (PKs y FKs) y carga inicial de datos.
2. **`RetailPro/m4_consultas_negocio.sql` (Módulo 4):** Consultas SQL avanzadas orientadas a responder preguntas estratégicas del negocio (resumen mensual, ranking de productos, clientes recurrentes y análisis de rendimiento mediante `CASE WHEN`).

---

## 🚀 ¿Cómo ejecutar este proyecto?
1. Cloná o descargá este repositorio en tu computadora.
2. Abrí tu entorno de SQL Server.
3. Ejecutá primero el script `ventas_tech_db.sql` para crear la estructura y poblar las tablas.
4. Ejecutá el script `RetailPro/m4_consultas_negocio.sql` para visualizar los reportes y métricas comerciales.
